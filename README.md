# Système d'Analyse des Habitudes Numériques des Étudiants

## 📌 Présentation
Ce projet vise à analyser l'impact du numérique (IA, réseaux sociaux, sommeil) sur le quotidien des étudiants. Réalisé dans le cadre du module **Digital Skills & IA** à la FST de Tanger.

## 🛠️ Compétences & Outils
- **Analyse de données :** Excel (Tableaux de bord, KPIs, Modélisation).
- **Développement Web :** HTML5 / CSS3 pour la présentation des résultats.
- **Rédaction :** Rapport technique et présentation structurée.
- **Collaboration :** Travail réalisé en binôme (avec Salma El Addaoui).

## 📊 Résultats Clés
- Analyse portée sur 30 étudiants.
- Détection automatique des alertes de dépendance numérique via des seuils de référence.
- Visualisation des corrélations entre temps d'étude et usage de l'IA.

## 📂 Contenu du dépôt
- `/data` : Données d'enquête et fichiers de calcul.
- `/docs` : Rapport complet et support de présentation.
- `index.html` : Interface web du tableau de bord.
